# Лад

Дневник настроения: отметки 1–5, заметки, история, локальное сохранение и добровольная облачная синхронизация через Supabase.

## Разработка

Node.js 22+, `npm ci`, `npm test`, `npm run build`.

## GitHub Pages

В Settings → Pages выбрать Source: GitHub Actions. Workflow pages.yml проверяет и публикует приложение после изменений main.

Приложение поддерживает размещение в подпапке репозитория. Облачные данные защищены политиками доступа Supabase; клиент содержит только публичный publishable key. Серверные секреты не входят в репозиторий.

Перед использованием на iPhone остаётся ручная проверка установки, верхней безопасной области, доставки писем и уведомлений.
